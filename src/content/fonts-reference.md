# Typography Configuration Reference

This file documents the previous typography choices used across the project in case specific parts need to revert or adopt them in the future.

## Previous Typography Configurations

### Original Configuration
* **Body / Default (`--font-sans`)**: `'DM Sans', system-ui, sans-serif`
  * Weights used: `400`, `500`, `600`, `700`
  * Used for body copy, buttons, badges, descriptions, and UI controls.
* **Headings (`--font-heading`)**: `'Manrope', sans-serif`
  * Weights used: `600`, `700`, `800`
  * Used for `h1` hero title, `h2` section titles, `h3` course names, and brand title.

### Intermediate Configuration
* **Default Sans**: `'Merriweather Sans', system-ui, sans-serif`
* **Headings**: `'Manrope', sans-serif`

### Current Unified Configuration
* **All Typography (`--font-sans` & `--font-heading`)**: `'IBM Plex Sans', system-ui, sans-serif`
  * Source: Google Fonts `IBM Plex Sans` (variable `wght@0,100..700;1,100..700`)
  * Applied globally to all headings, body, cards, and UI components.

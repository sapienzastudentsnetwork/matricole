# Matricole 2026/2027 Landing Page

Landing page statica, costruita con Astro e DaisyUI. 

- Responsiva 
- Leggera 
- Moderna 
- Multilingua (Espandibile)



## Requisiti di build 
- Node.js 22+ (con Corepack integrato)
- Yarn Berry

### Comandi

```bash
# Abilita Corepack
corepack enable

# Installa dipendenze
yarn install

# Avvia server di sviluppo
yarn dev
```

Astro espone il server su 
```bash 
localhost:4321 
```
di default. 


### Build di produzione

```bash
# Genera sito statico
yarn build

# Anteprima build
yarn preview
```

Il sito viene generato nella cartella `dist/`.

## Styling 

Lo stile del progetto è contenuto e documentato in `/src/assets/global.css`.
